# Meu Segundo Repositorio

Repositorio do exercicio 1.3 de Transformacao Digital.

Criado e clonado com o GitHub CLI por um agente de codificacao, a pedido do usuario.

## Comandos utilizados

- gh repo create: cria o repositorio no GitHub.
- gh repo clone: copia o repositorio para o computador.
- git add e git commit: preparam e registram o README no historico.
- git push: envia o commit ao GitHub.
